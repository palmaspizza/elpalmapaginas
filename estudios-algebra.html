VP

Variación Porcentual

VP = ((VF − VI) / VI) × 100
  • VP positivo: el valor aumentó
  • VP negativo: el valor disminuyó
  • Unidad: siempre en %
  • Ejemplo: 100 → 120 ⟹ VP = 20%
VI

Valor Inicial

VI = VF / (1 + VP/100)
  • Se usa cuando conocemos el precio final
  • y sabemos cuánto subió o bajó
  • Ejemplo: VF=990, VP=11.2% ⟹ VI≈890
VF

Valor Final

VF = VI × (1 + VP/100)
  • Partimos del precio original
  • y aplicamos el porcentaje de cambio
  • Ejemplo: VI=500, VP=20% ⟹ VF=600
R3

Regla de 3

x = (b × c) / a
  • Si a corresponde a b
  • entonces c corresponde a x
  • Ejemplo: 100%→150, 20%→x ⟹ x=30
